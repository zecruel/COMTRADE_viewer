# COMTRADE Viewer
Read and plot COMTRADE (IEEE C37.111) files from local storage.

## Try it:
# [https://zecruel.github.io/COMTRADE_viewer/main.html](https://zecruel.github.io/COMTRADE_viewer/main.html)


Author: ZeCruel - 05/2026

    Used libraries:
    
    * w2ui - https://github.com/vitmalina/w2ui - for GUI features (grid, buttons)
    * echarts - https://github.com/apache/echarts - for interactives plot charts
    * fparse - https://github.com/bylexus/fparse - for math expressions evaluation
